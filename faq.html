Foire Aux Questions

Comment s'effectue le paiement ?

Les règlements s'effectuent directement via Stripe (Carte bancaire, Apple Pay, Google Pay). Dès la validation, le travail sur votre projet est automatiquement débloqué.

Comment puis-je communiquer avec le développeur ?

Une fois votre compte créé, vous disposez d'un canal de discussion privé rattaché à votre projet directement dans votre Espace Client MDCP.

Suis-je propriétaire du code source ?

Oui, l'intégralité du code développé pour votre projet vous appartient une fois la livraison effectuée.
